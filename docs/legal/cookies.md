OmniReview does not use advertising or analytics cookies.

- **Your sign-in session** is kept in the page's memory only, so it ends when you close or reload the tab. It is not
  stored in a cookie.
- **Local storage** in your browser remembers only that you have dismissed this notice.
- **Fonts and scripts** are served from our own servers; the app does not load resources from third parties.

Because this storage is strictly necessary or only remembers a choice you made, it doesn't need consent. If we ever
add optional cookies, we will ask first.
