# Getting started

OmniReview supports a systematic review from the first question to publication and living updates. The AI suggests;
reviewers decide. Every decision, AI output, and sign-off is recorded in the project's audit trail.

## Create an account and a project

1. Register with your name, email address, institution, and role, then sign in.
2. On the dashboard, create a project and give it a title.
3. Open the project. The sidebar lists the screens in workflow order, from Project Setup to Living Review.

## Choose an AI model and add keys

Each project pins one AI model in **Project Setup**, so everyone on the review uses the same model. A project can use
a model when the server has a key for its provider or when you have saved your own key. Add your own keys under
**Settings**; they are encrypted and never shown again after saving.

## Invite your team

Open **Share / Collaborate** in the project sidebar, or **Team & Tasks**, to invite people by email with a role. See
[Collaboration](collaboration.md) for what each role can do.

## Work through the stages

A review moves through ten stages: protocol, search and deduplication, title and abstract screening, full-text
screening, data extraction, risk of bias assessment, synthesis, certainty of evidence (GRADE), manuscript, and
submission and deposit. Each screen shows its stage's sign-off box with the requirements still unmet. See
[Workflow and sign-offs](workflow.md).

## Get help

Use the help assistant (the chat button at the bottom right). It answers from this documentation and links the pages
it used. When the documentation doesn't cover a question, it says so.
