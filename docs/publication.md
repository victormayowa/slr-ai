# Submission and publication

OmniReview prepares and checks a submission but never submits: the corresponding author confirms the package and submits
it on the journal's own system.

## Journal finder

Candidate journals come from OpenAlex (journals publishing on the topic and where the included studies appeared), with
open access status, publication fees, DOAJ listing, MEDLINE indexing, and metrics. Warnings such as "not in DOAJ" are
heuristic flags, not verdicts; check journals with Think. Check. Submit.

## Author guidelines

Give a link, a PDF or Word file, or pasted text. The AI lists requirements (word limits, abstract structure, reference
style, figure formats, required statements), each with a quote that must be found in the guidelines; requirements whose
quotes aren't found are shown but not used. Correct any value by hand.

## Submission package

A package is built from the approved manuscript version: the manuscript (Word, PDF, LaTeX), title page, abstract,
keywords, highlights, cover letter, statements (funding, competing interests, data availability, registration, CRediT
contributions, AI use), tables, figures, and supplements (search strategies, PRISMA flow, the extraction data set,
analysis bundles, checklists, the protocol). Readiness checks cover approval, verification, retractions, the PRISMA
checklist, word limits, reference and figure limits, figure formats, keywords, highlights, and statements.

## Repository deposits

Deposit data, code, and materials as a FAIR package (README, data dictionary, CC BY 4.0 licence, DataCite metadata) on
Zenodo, Figshare, OSF, GitHub, or GitLab, or download a guided package for Dryad, medRxiv, or OSF Preprints. Access
tokens are used for the deposit only and never stored. Zenodo and Figshare deposits stay drafts unless you choose to
publish.

## Peer review

Record each review round, paste or upload the reports (split into comments by reviewer and number, or by the AI, keeping
only verbatim text), respond point by point, link responses to manuscript revisions, reopen stages for re-analysis, and
draft the response letter.
